# SokoSmart

SokoSmart is a machine learning-based demand forecasting and inventory decision-support system designed for small fashion vendors.

The system analyses historical sales data to forecast future demand and support inventory replenishment decisions. Vendors will interact with the system through WhatsApp.

## Project Goals

- Analyse historical fashion sales data
- Forecast product demand using ARIMA, XGBoost and LSTM
- Compare model performance using RMSE, MAE and MAPE
- Support inventory reorder decisions
- Provide vendor interaction through WhatsApp
